Assessment Idea (CAP 6318)

  • Reasoning & Pseudocode credit: Student submits algorithmic steps demonstrating computational problem decomposition.
  • Faithful execution: The LLM is restricted from fixing logic bugs or inventing steps; code correctness directly reflects specification rigor.
  • Pedagogical separation: Students receive the convenience of AI-assisted language syntax without outsourcing the core problem-solving process.
